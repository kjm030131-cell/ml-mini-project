## 프로젝트 1: EMNIST 손글씨 숫자

- 데이터: `emnist-digits-train.csv`, 240,000행 × 785열(정답 1 + 픽셀 784), 숫자별 24,000개씩 균등
- 슬라이드 기준선: SGDClassifier 10-fold 평균 0.8845

### 최종 제출 조합

- **특성 2,629개** (`mini_proj_01_20221329.ipynb` 4번 셀)
  - 기울기 보정(deskew) 이미지 픽셀 784개: 이미지 모멘트로 기울기를 구해 숫자를 똑바로 세운 것
  - 촘촘한 HOG 1,521개: 4×4 칸을 2칸씩 겹쳐 이동하며 획 방향 9구간 히스토그램
  - 큰 칸 HOG 324개: 8×8 칸을 4칸씩 이동
- **모델**: `SVC(C=10)` (RBF 커널)
- **로컬 결과 (M4 맥북)**: 처음 7개 fold가 0.997, 0.996, 0.996, 0.997, 0.996, 0.997, 0.996 (fold당 약 19분). 예상 평균 약 0.9964

### 규칙 점검

| 항목 | 내용 |
|---|---|
| 모델 | SVC, SGD (사용 가능 목록) |
| GPU | 미사용 |
| 증강 | 미사용. 이미지 개수는 24만 개 그대로. 기울기 보정은 각 이미지를 변환해 특성으로 쓰는 것이라 데이터를 늘리지 않음 |
| PCA | 미사용 |
| StratifiedKFold | import하지 않고 강의 코드처럼 `cv=10`만 사용 |
| 특성 엔지니어링 근거 | W15-01 8쪽 "자신만의 특성 추출", W01 45쪽 특성 추출 정의(강의자 의견), W06 31쪽 "분류에 도움 되는 특성 찾기" |

### 실험 기록

실험은 클라우드(2코어, 7GB)에서 일부 데이터로 진행했다. 표의 점수는 제출 점수가 아니라 조합을 고르기 위한 비교값이다.

#### 1차: 특성과 모델 비교 (`exp1.py`, 2만 개, 3-fold)

| 조합 | 정확도 |
|---|---|
| LGBM + 원본 픽셀 | 0.9733 |
| LGBM + 기본 특성(가로·세로 합, 4×4 블록 평균, 잉크 양) | 0.9748 |
| LGBM + 기본 특성 + HOG | 0.9841 |
| SVC + 원본 픽셀 | 0.9741 |
| SVC + 기본 특성 + HOG (표준화) | 0.9771 |

→ HOG 효과가 큼.

#### 2차: 구멍 개수 특성, LGBM 설정 (`exp2.py`, 2만 개, 3-fold)

W06 31쪽 "동심원 개수(8은 2개, 6은 1개, 5는 0개)" 예시를 구멍 개수 특성으로 구현.

| 설정 | 정확도 |
|---|---|
| 트리 300, lr 0.1 | 0.9854 |
| 트리 600, num_leaves 63 | 0.9856 |
| 트리 1000, lr 0.05 | 0.9867 |

→ 구멍 개수 +0.0013. 트리 수를 늘리는 효과는 작음.

#### 3차: 데이터 양에 따른 LGBM (`exp3.py`, 홀드아웃 1만)

| 학습 데이터 | 정확도 |
|---|---|
| 2만 | 0.9863 |
| 5만 | 0.9908 |

#### 5차: 기울기 보정 (`exp5a.py`, `exp5b.py`, 학습 5만 / 홀드아웃 1만)

| 조합 | 정확도 |
|---|---|
| SVC + 원본 픽셀 | 0.9833 |
| SVC + 보정 픽셀 | 0.9898 |
| SVC + 보정 HOG(4, 7) | 0.9924 |
| SVC + 원본 HOG + 보정 HOG | 0.9926 |
| SVC + 보정 픽셀 + 보정 HOG | 0.9929 |
| LGBM + 기본 특성 + HOG + 구멍 | 0.9909 |
| LGBM + 위 특성 + 기울기 보정 | 0.9930 |

→ 기울기 보정이 SVC, LGBM 모두에서 큰 효과.

#### 6차: 촘촘한 HOG, SVC 설정 (`exp6.py`, 학습 5만 / 홀드아웃 1만)

| 조합 | 정확도 |
|---|---|
| 보정 픽셀 + 보정 HOG(4, 7) | 0.9932 |
| 촘촘한 HOG(4칸, 2칸 이동) | 0.9938 |
| 보정 픽셀 + 촘촘한 HOG | 0.9940 |
| **보정 픽셀 + 촘촘한 HOG + 큰 칸 HOG** | **0.9943** |
| 보정 픽셀 + 촘촘한 HOG, C=30 | 0.9941 |
| 보정 픽셀 + 촘촘한 HOG, gamma 2배 | 0.9943 |

→ 최종 특성 조합 결정.

#### 7차·9차: 다른 모델과 합치기 (`exp7.py`, `exp9a.py`, 학습 5만 / 홀드아웃 1만)

| 모델 | 정확도 |
|---|---|
| SVC | 0.9931 |
| LGBM | 0.9930 |
| RandomForest | 0.9906 |
| LogisticRegression | 0.9905 |
| ExtraTrees | 0.9898 |
| SVC + LGBM 확률 평균 (SVC 비중 0.7) | 0.9941 |

- SVC 69개, LGBM 70개 오답 중 둘 다 틀린 것은 42개
- 5개 모델이 모두 틀린 것은 29개

#### 8차: SVC 데이터 양 (`exp8.py`, 홀드아웃 1만)

| 학습 데이터 | 정확도 | 학습 시간 |
|---|---|---|
| 5만 | 0.9938 | 114초 |
| 12만 | 0.9947 | 706초 |

#### Stacking (`s_svc.py`, `s_lgbm.py`, 학습 5만 / 홀드아웃 2만)

| 조합 | 정확도 |
|---|---|
| SVC 단독 | 0.9951 |
| LGBM 단독 | 0.9938 |
| LogisticRegression 단독 | 0.9916 |
| SVC + LR Stacking | 0.9944 |
| SVC + LGBM Stacking | 0.9955 ~ 0.9956 |
| SVC + LGBM + LR Stacking | 0.9952 ~ 0.9954 |

→ +0.0004~0.0005. 전체 10-fold에서는 12시간 이상 걸릴 것으로 보여 보류.

#### 10차: 추가 특성과 커널 (`prep10.py`, `exp10.py`, 학습 5만 / 홀드아웃 2만)

| 방법 | 정확도 | 오답 (2만 개 중) |
|---|---|---|
| 기준 (최종 조합) | 0.9950 | 100 |
| 제곱근 변환 | 0.9951 | 97 |
| HOG 12방향 | 0.9951 | 97 |
| gamma 2배 | 0.9951 | 98 |
| 기준 + 크기 정규화 | 0.9950 | 100 |
| 크기 정규화만 | 0.9940 | 121 |
| 다항식 커널 4차 | 0.9948 | 103 |
| 다항식 커널 3차 | 0.9945 | 109 |

→ 모두 오차 범위 안이거나 더 나쁨. 특성·설정 변경으로는 더 오르지 않음.
