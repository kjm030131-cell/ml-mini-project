# R8: 규모 확인 — 기준 SVC(오답 100 조합)를 학습 10만으로 (2026-11-18, 연구 세션 13회차 직접 실행)

**결론: 학습 10만에서 기준 SVC 오답 83 — R5 의 15차 특성 SVC(10만 86)보다 오히려 3개 적음.** 5만에서 보였던 15차 특성의 이득(100→88, −12)은 학습이 10만으로 늘면 사라진다(우연 범위 안에서 역전). 메인 세션이 기록한 24만 10-fold 실제 결과(기준 SVC 0.9964125, Stacking 0.9964625, 차이 +0.00005)와 같은 방향.

- 의미 1: **'학습 5만' 비교에서 나온 개선은 전체 데이터로 옮겨지지 않는다.** 5만 기준 개선(특성 추가 −12, Stacking −22)은 대부분 '데이터가 적을 때 도움 되는 정보'였고, 데이터가 많으면 기준 SVC 가 스스로 배움
- 의미 2: 제출용으로는 **기준 SVC 단일(24만 10-fold 0.9964125, 198분)이 Stacking(0.9964625, 1191분)과 사실상 같음**. 앞으로 비교는 학습 10만 이상(또는 채점 구간 여러 개)으로 해야 의미가 있음
- 5→3 은 10만에서도 7개로 1위 (R5 와 동일)
- 설정: 보정 픽셀 + HOG(4,2) + HOG(8,4) 각 비중 1, SVC C=10, gamma 1.0배(=1/(특성수·분산)), 학습 앞 10만, 채점 220000~240000. 비교 대상 R5 10만 = 15차 prof 조합, gamma 1.2배
