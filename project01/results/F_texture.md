# 실험 F: 질감 특성 LBP·가보르

- 날짜: 2026-11-17
- 설정: SVC(C=10), 기준 특성 = 기울기 보정 픽셀 x1 + HOG(4,2) x1 + HOG(8,4) x2, gamma 1.2배 (실험 B 최고). 학습 앞 5만 / 채점 220000~240000 (2만)
- **결론: 개선 없음.** 기준 95개 대비 LBP·가보르 추가 시 94~101개로 차이가 ±6개 이내(우연 범위). 오답 10개 이상 감소 기준을 충족한 조합이 없어 LBP·가보르는 채택하지 않음. 가보르 단독(94개, -1)이 가장 좋았지만 의미 없는 차이이고, LBP는 오히려 +2개. gamma 1.0으로 낮추면 101개로 악화 → gamma 1.2배 유지.
