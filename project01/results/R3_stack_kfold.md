# 실험 R3: 제출 노트북 Stacking 내부 cv 를 KFold(2) 로
- 날짜: 2026-11-18 (KST), 연구 세션 5회차가 직접 실행 (예약 실행에서 실험 세션 생성이 승인 필요로 거부돼서)
- 비교: 기준선(단일 SVC) 100 / 제출 노트북 정수 cv=2(=StratifiedKFold) Stacking 80 / 메인 16차 수동 Stacking 78

- 추가로 제출 노트북 셀 7 `cross_val_score(cv=10)` 도 정수라 StratifiedKFold 가 되므로 `cv=KFold(n_splits=10)` 객체로 바꿔야 함 (셀 6 의 cv=3 도 같음)
- 가장 많이 틀린 쌍: 5→3 10개, 7→2 6개, 3→2 5개 (3↔5 합 13개, 여전히 1위)
