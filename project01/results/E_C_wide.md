# 실험 E: C 넓은 범위 탐색 (gamma 1.2배 고정)

- 날짜: 2026-11-17
- 특성: 기울기 보정 픽셀(×1) + HOG(4,2)(×1) + HOG(8,4)(×2), SVC RBF, gamma = 기본값 × 1.2
- 평가: 학습 앞 5만 개, 채점 220000~240000번 2만 개 (오답 수)
- 결론: **진짜 개선 없음.** 최고는 C=5 오답 94개로 기준선(100개) 대비 6개, 실험 B(C=10·gamma 1.2배, 95개) 대비 1개 감소에 그쳐 우연 범위(10개 미만)다. C=3~100 구간은 94~96개로 거의 평탄하고, C=1만 101개로 약간 나빠진다. C는 3~100 어디를 써도 무방하며 기존 C=10을 유지해도 된다.
