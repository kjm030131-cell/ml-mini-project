# 실험 G: HOG 계산 방식 개선

- 날짜: 2026-11-17
- 설정: SVC(C=10, gamma 1.2배), 기울기 보정 픽셀 + HOG 변형. 학습 앞 5만 / 채점 220000~240000 (2만 개)
- **결론: 진짜 개선 없음.** 최고는 '흐림 + 부호 있는 방향'으로 오답 90개(기준 95개 대비 -5개)지만, 판정 기준(10개 이상 감소)에 못 미쳐 우연 범위로 본다. 부호 있는 방향·흐림 단독은 +3개, Dalal-Triggs 블록 정규화는 +14개(악화), 기준에 DT 블록 추가는 +2개로 모두 개선 아님.
- 참고: 두 프로세스 동시 실행 중 1번 프로세스가 메모리 부족(OOM, 8GB 한도)으로 '흐림 + 부호 있는 방향' 학습 중 종료됨. 남은 2개(흐림+부호, 기준+DT 블록)는 같은 설정으로 단독 재실행함 (`G_1_rerun.out`).
